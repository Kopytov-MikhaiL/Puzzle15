# Puzzle15
игра "Пятнашки" на C++
# Задача
Написать игру "Пятнашки" по следующему условию:
Поле представлено в виде массива 4 на 4, где одна ячейка остается пустой, что позволяет
перемещать соседние плитки. Цель игры — упорядочить плитки так, чтобы они образовали
последовательность от 1 до 15, оставив пустую ячейку в правом нижнем углу.
# Функциональность
• генерация корректной стартовой позиции
• перемещение плиток
• проверка победы
• сохранение и загрузка игры
